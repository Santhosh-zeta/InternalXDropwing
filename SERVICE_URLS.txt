🚀 QUICK DEPLOYMENT

  1. Install cloudflared:
     → brew install cloudflare/cloudflare/cloudflared

  2. Authenticate:
     → cloudflared tunnel login

  3. Create tunnel:
     → cloudflared tunnel create internalx-tunnel

  4. Configure & deploy:
     → ./deploy-with-tunnel.sh
