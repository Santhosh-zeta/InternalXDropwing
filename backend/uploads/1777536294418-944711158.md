## 🔥 Top Next Features to Build

### 1. 📊 Reports & Analytics View
**Who:** L1–L5  
**What to build:**
- Cross-venture performance charts (tasks completed, projects on-time rate)
- Revenue vs. spend charts per venture
- Team productivity heatmap by week
- Export to PDF / CSV buttons
- Date range picker filters

**Backend needed:** Extend `analytics.routes.js` (already exists!) with more aggregation queries.

---

### 2. 🔐 Access Control Panel
**Who:** L1 Super Admin only  
**What to build:**
- Visual permission matrix (rows = levels L1-L9, columns = features)
- Toggle switches to grant/revoke access per level per feature
- Role reassignment for individual users
- Session management — view & kill active sessions

**Backend needed:** New `access_control.routes.js`, read/write to `access_levels.permissions` JSON column.

---

### 3. 🧾 Client Portal (L9)
**Who:** L9 Clients  
**What to build:**
- Read-only project status tracker with timeline/Gantt view
- Deliverables checklist with approval buttons
- Invoice download & payment status display
- Secure file sharing (client-specific documents)
- Branded per-venture theme (Dropwing purple, SerphoSoft cyan, etc.)

**Backend needed:** Filter all endpoints by `client_id` + `venture_id`.

---

### 4. 📈 Department KPIs / CXO Dashboard (L4)
**Who:** L4 CXO  
**What to build:**

- Budget allocation widget

### 5. 💰 Budget / Financials Module (L2–L4)

### 6. 🏢 HR Overview Module (L2 MD)
